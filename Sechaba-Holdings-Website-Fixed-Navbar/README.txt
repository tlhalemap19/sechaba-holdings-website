SECHABA HOLDINGS WEBSITE - FIXED NAVBAR EDITION
Rebuilt from the previously created website structure and supplied project photographs.

Extract the complete ZIP, then open index.html. Keep the assets folder beside the four HTML pages. No installation or build step is needed.

The navigation remains fixed to the top of the viewport on all four pages. Its height is measured automatically so wrapped mobile navigation does not cover page content. Anchor links leave clearance below the navbar.

Includes Services, combined About & Gallery, and Contact pages; 16 gently enhanced photographs, gallery filters and enlarged image viewer. The blurry interior image is omitted. No photo objects were removed or generated. Colours and text branding are proposed.

The quotation form opens an email app; the visitor must send the email. There is no server-side form handling, database, analytics or payment system. No WhatsApp number assumed.

Review all business details and photo permissions before publishing. To publish, upload all four HTML files and assets folder to a static host with index.html at the root. This ZIP is not an online deployment.
